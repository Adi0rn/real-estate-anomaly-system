## 4. Security & Safety Invariants

1. **Role Enforcement:** All DBMS Operations and Schema Explorer endpoints strictly require an active session belonging to an authenticated `ADMIN` user (`requireAdmin`). Ordinary `USER` accounts receive HTTP 403 Forbidden.
2. **Title Prefix Isolation:** All properties created through the console automatically receive the `[DBMS CONSOLE] ` prefix. Modifying or deleting any property lacking this prefix is blocked with HTTP 403 Forbidden.
3. **Owner Verification:** Modifying or deleting a console property strictly checks that `ownerId` matches the authenticated administrator's `userId`. An admin cannot modify or delete another admin's properties.
4. **Lifecycle Guard:** Only properties with status `DRAFT` can be updated or deleted through the console.
5. **Trigger Deduplication:** Exactly one non-internal trigger (`property_price_history_trigger`) exists on `Property`. Its `WHEN (OLD.price IS DISTINCT FROM NEW.price)` clause guarantees exactly one history entry per genuine price shift and zero history on no-op updates.
6. **No Arbitrary SQL Execution:** No raw or client-supplied SQL statements are accepted from browser inputs.

```sql
CREATE TRIGGER property_price_history_trigger
AFTER UPDATE OF price ON "Property"
FOR EACH ROW
WHEN (old.price IS DISTINCT FROM new.price)
EXECUTE FUNCTION record_property_price_history()
```

### 2. Trigger Function Definition (`pg_proc` via `pg_get_functiondef`)
```sql
CREATE OR REPLACE FUNCTION public.record_property_price_history()
 RETURNS trigger
 LANGUAGE plpgsql
AS $function$
BEGIN
    INSERT INTO public."PriceHistory" ("propertyId", "price", "recordedAt")
    VALUES (NEW."propertyId", NEW."price", CURRENT_TIMESTAMP);
    RETURN NEW;
END;
$function$
```
- **Inserted Attributes:** `NEW."propertyId"`, `NEW."price"`, `CURRENT_TIMESTAMP`.
- **Target Entity:** `public."PriceHistory" ("propertyId", "price", "recordedAt")`.
- **Nonexistent Columns:** None. Returns `NEW`.
